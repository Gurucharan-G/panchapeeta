# Mutt / Monastery Photos

Place photos of the five Peetha monasteries (Mutts) here.

**Expected filenames** (must match Peetha slugs):

| File | Mutt / Monastery | Location |
|------|-----------------|----------|
| `rambhapuri-peetha.jpg` | Rambhapuri Peetha | Balehonnur, Karnataka |
| `ujjaini-peetha.jpg` | Ujjaini Saddharma Peetha | Ujjini, Vijayanagara, Karnataka |
| `kedara-peetha.jpg` | Kedara Peetha | Kedarnath, Uttarakhand |
| `srisaila-peetha.jpg` | Srisaila Peetha | Srisailam, Andhra Pradesh |
| `kashi-peetha.jpg` | Kashi Peetha (Jangamwadi Math) | Varanasi, Uttar Pradesh |

**Note**: The filename must match the `slug` field of the Peetha model. Supported formats: `.jpg`, `.png`, `.webp`

These will appear as the main photo in the center of each card.
