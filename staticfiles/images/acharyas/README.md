# Acharya Portrait Photos

Place the portrait photos of the five founding Acharyas here.

**Expected filenames** (must match Peetha slugs):

| File | Acharya | Peetha |
|------|---------|--------|
| `rambhapuri-peetha.jpg` | Jagadguru Renukacharya | Rambhapuri Peetha |
| `ujjaini-peetha.jpg` | Jagadguru Marulasiddheshwara | Ujjaini Peetha |
| `kedara-peetha.jpg` | Jagadguru Ekoramacharya | Kedara Peetha |
| `srisaila-peetha.jpg` | Jagadguru Panditaradhyacharya | Srisaila Peetha |
| `kashi-peetha.jpg` | Jagadguru Vishwaradhyacharya | Kashi Peetha |

**Note**: The filename must match the `slug` field of the Peetha model. Supported formats: `.jpg`, `.png`, `.webp`

These will appear as circular profile photos protruding from the top of each card.
